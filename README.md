### Sandbox for getting started on with metal-cpp (metal with c++ wrapper)

**How to use**

- clone repo
```bash
git clone -b xcode https://github.com/Thaparoshan143/Sandbox_Metal-cpp path/to/clone
```

- open project in xcode (terminal command is as)
```bash
xed .
```

**Requirements**
- macOS 15.2+
- Xcode (also, command line tools)

> [!Note]
> This is created on/for Apple Silicon (namely M1, macOS). Please refer to the Apple developer website for further information, [here](https://developer.apple.com/metal/cpp/)
